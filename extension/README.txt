MSM Forma Scanner (Chrome / Edge)
1. Open chrome://extensions (or edge://extensions), turn on Developer mode.
2. Load unpacked, choose this "extension" folder.
3. In MSM: Autodesk Forma, connect the project URL.
4. In MSM press Autodesk Forma > Scan Models > Scan now. Forma opens, sets the search and scans by itself (if it cannot set the filters, set Files + RVT yourself and press the blue button).
5. The result opens in MSM by itself. Press Save to project.
No API, no sign-in, nothing leaves your browser.
