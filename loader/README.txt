MSM Forma Scanner (auto-update) - ONE-TIME SETUP
1. Unzip this folder somewhere permanent (for example Documents\MSM-Scanner).
2. Open chrome://extensions, turn ON Developer mode, press Load unpacked, choose this folder.
   (If you installed the old "MSM Forma Scanner", remove it first.)
3. On the new extension's card press Details and turn ON "Allow User Scripts".
4. Press the extension's icon once (puzzle piece menu). A green tick means the code was loaded from GitHub.

After that the scanner code updates itself from GitHub (checked every 30 minutes and whenever Chrome starts).
To force an update immediately, press the extension's icon. Badge "OFF" = step 3 is missing.
