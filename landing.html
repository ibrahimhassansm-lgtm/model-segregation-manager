Model names sit in one sheet, links in another, and the structure in someone's head. When a model is added, nobody is sure what it should link to.

One register replaces all of them

Questions

Do I need to install anything?

No. It runs in your browser. Open it and sign in.

Can several people work on the same project?

Yes. Projects are shared, so the whole team reads and works from the same register.

Can I control who edits the register?

Yes. Roles decide who can edit and who can only view.

Can I start a new project from an old one?

Yes. Save a project as a template, then create new projects from it and adjust what differs.

What does the link matrix show?

It shows which models are linked into which other models, so a missing or unexpected link is easy to spot.

Can I see what changed in a project?

Yes. The activity view lists the changes made to a project.
