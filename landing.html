What it does

One page per project, built around the way model segregation is actually planned.

Model register

Every model with its code, discipline, zone and type, grouped and filterable, so the list is never a spreadsheet you have to trust.

Link matrix

See which models link to which, spot missing or extra links, and keep the link plan in one agreed place.

Model structure and map

View the structure of the project and how models sit inside it, instead of reading it from folder names.

Codes

Naming codes for disciplines, zones and types live in the project, so new models follow the same rules.

Project templates

Start a new project from an existing one and keep what carries over, instead of rebuilding the register.

Roles and activity

Control who can edit, and see an activity log of what changed and when.

How it works

Open a project or start onePick an existing project, or create one from a template.

Register the modelsAdd models with their codes and set which models they link to.

Check and shareReview the link matrix and structure, then work from the same register as the rest of the team.

Questions

Do I need to install anything?

No. MSM runs in your browser. Open it and sign in.

Can several people use the same project?

Yes. Projects are shared and roles decide who can edit and who can only view.

Can I start a new project from an old one?

Yes. Save a project as a template and create new projects from it.
